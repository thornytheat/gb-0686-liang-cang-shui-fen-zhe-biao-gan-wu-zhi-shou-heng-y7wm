# 字段与计算定义

id、bin为字符串，保留前导零；version为正整数。gross、tare为毛重与皮重，unit仅kg或t。净重先换算kg，且毛重不小于皮重。
moisture、impurity为百分数，取值[0,100)，水分超过max_moisture拒收。标准水分必须小于收购上限且低于100。
净粮=净重×(1-杂质/100)，干物质=净粮×(1-水分/100)，折标重=干物质/(1-标准水分/100)。
单价CNY/kg，按未舍入折标重计算总额，再以最大余额法分配分币，余数相同按id升序。全部金额和重量为Decimal，JSON以字符串输出。
同键最高版本采信；同版数值不一致时该键所有行隔离，完全相同则保留最早行。旧版与重复行计入隔离，保证输入行数平衡。
时间仅用于运行清单，保存UTC偏移。空值、哨兵、零分别处理，空文件/仅表头/全空行返回不同原因码。规则参数纳入批次哈希。

## 车次账台（地磅毛皮分录）

称重流水CSV字段：`event_id,plate,kind,weight,unit,weighed_at,bin,moisture,impurity` 九列齐全。event_id、plate为字符串，保留前导零；kind为gross/毛重或tare/皮重；weight按unit换算kg，整数去小数尾；weighed_at为带偏移的ISO时间，仓批日期取毛重当地时间。bin、moisture、impurity仅毛重行必填，皮重行留空；水分超过max_moisture的毛重行按LIMIT隔离，其皮重落单待配。

配对：每条皮重绑定同车、称重时间在其之前最近的未配对毛重，皮重只消费一次；绑定只增不改。皮重不小于候选毛重时双方留待人工，不入账。暂估：未配皮重的车次用同车称重时间在其之前的最近一次实称皮重估算净重，无则用default_tare_kg参数，再无则记待皮重；暂估只作占位，真皮重入账后原位替换重算。

幂等：上传批次ID=SHA256(原文+参数)前20位，同内容重传直接重放；称重号唯一，同号同内容计DUPLICATE，同号不同内容计CONFLICT并采信首次入账。折标参数以首次上传为准锁定，不一致返回409 PARAMS_LOCKED。

结算：仓批=仓号×毛重日期。车次确认时金额=R(仓批累计精确额)−已确认累计额，R为四舍五入到分；仓批已定合计恒等于R(精确总额)，已定车次金额冻结不变。未确认车次按自身精确额四舍五入列暂估，仓批合计=已定+暂估。导出已定磅单为M1契约CSV，逐仓批与M1–M6管线总额一致。
